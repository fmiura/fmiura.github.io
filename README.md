# fmiura.github.io

## UTM campaign convention

Use the following UTM parameters when sharing links to the website:

**LinkedIn**

```text
utm_source=linkedin
utm_medium=social
```

Example:

`https://fmiura.github.io/research.html?utm_source=linkedin&utm_medium=social&utm_campaign=research_profile`

**Conference QR codes**

```text
utm_source=<conference-name>
utm_medium=qr
```

Example:

`https://fmiura.github.io/research.html?utm_source=example-conference&utm_medium=qr&utm_campaign=heterogeneity`

Recommended campaign names:

- `research_profile`
- `heterogeneity`
- `epidemic_intelligence`
- `targeted_control`
