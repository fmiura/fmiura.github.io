Training resources for infectious disease modelling

A curated list of courses, summer schools, online materials, textbooks, and tutorials for epidemiological statistics, infectious disease modelling, mathematical epidemiology, stochastic processes, and network science.
Published

July 3, 2026

Note

This page is a curated resource list for students, PhD candidates, postdocs, and collaborators interested in infectious disease modelling, epidemiological statistics, mathematical epidemiology, stochastic epidemic models, model fitting, outbreak analytics, and network science.

Course dates, fees, eligibility rules, and application deadlines change frequently. Always check the official course page before applying. The selections and notes are personal and do not represent any affiliated institution.

Last manually checked: 2026-07-03
Maintainer: Fuminari Miura

How to use this page

The resources below are grouped by training purpose rather than by institution. A practical learning route is:

  1. start with epidemiological statistics and regression;
  2. learn basic infectious disease modelling;
  3. add mathematical epidemiology and stochastic epidemic models;
  4. learn model fitting and inference;
  5. specialize into network science, outbreak analytics, or agent-based modelling.

The labels in the notes are informal:

Label Meaning
Core Strongly relevant for infectious disease modelling training.
Recommended Broadly useful for students or researchers.
Specialized Highly useful for a specific modelling subfield.
Reference Best used as self-study or supplementary material.
Archived / recurring Past or recurring event worth tracking for future editions.

Recommended training routes

Goal Suggested route
Epidemiological regression from the basics Imperial public-health R course → Nahhas regression book → WUR or Johns Hopkins regression/biostatistics
Basic infectious disease modelling Imperial infectious disease modelling specialization → LSHTM introduction or FUN-MOOC → Keeling & Rohani
Mathematical epidemiology Diekmann, Heesterbeek & Britton → ESPIDAM stochastic epidemic models → selected stochastic-process material
Stochastic epidemic models Allen primer → branching-process / CTMC material → ESPIDAM stochastic epidemic models → LSHTM model fitting
Model fitting and inference Statistical Rethinking → LSHTM model fitting and inference → Epiverse/outbreak analytics material
Network/contact modelling Utrecht network science → ESPIDAM networks/contact patterns → EpiModel/SISMID network modelling

Epidemiological statistics and regression

Resource Provider / format Level Main topics Notes
Statistical Analysis with R for Public Health Imperial College London / Coursera Beginner to intermediate R, statistical thinking, linear regression, logistic regression, survival analysis, public-health datasets Core. Good first course for epidemiological regression in R.
Biostatistics in Public Health Johns Hopkins / Coursera Beginner to intermediate Biostatistics, regression, inference, public-health applications Recommended. Useful for reading and conducting epidemiological analyses.
Multiple Regression Analysis in Public Health Johns Hopkins / Coursera Intermediate Multiple linear regression, logistic regression, Cox regression, splines, adjustment, effect modification Recommended. More focused regression course within the Johns Hopkins sequence.
Introduction to Regression Methods for Public Health Using R Ryan Nahhas / online book Beginner to intermediate Linear, logistic, and survival regression; public-health examples; R implementation Core reference. Good companion to any regression course.
Advanced Analytical Epidemiology Wageningen University & Research / online course Intermediate Logistic regression, generalized linear models, mixed models, Cox models, confounding, effect modification Recommended. Formal epidemiological analysis course in the Netherlands.
Statistical Modelling for Epidemiology University of Edinburgh / online MSc module Intermediate Linear regression, logistic regression, survival analysis, diagnostics, model building Recommended. Check whether single-course enrolment is possible.
Introductory Course in Epidemiology & Medical Statistics LSHTM / short course Beginner to intermediate Epidemiology, medical statistics, regression, confounding, study design, infectious disease epidemiology Recommended. Broad professional-training course.
Statistical Practice in Epidemiology using R Bendix Carstensen and collaborators / short course Intermediate Logistic regression, Poisson regression, survival analysis, multistate models, causal inference, R Specialized. Strong for classical epidemiological statistics in R.
Statistical Rethinking 2026 Richard McElreath / open course material Intermediate to advanced Bayesian regression, hierarchical models, causal models, posterior predictive checks, scientific modelling workflow Core reference. Especially useful before Bayesian infectious disease model fitting.
GAM resources Noam Ross / curated resources Intermediate Generalized additive models, mgcv, smooth terms, nonlinear effects, seasonality Specialized. Useful for seasonality, humidity effects, nonlinear time trends, and surveillance models.

Infectious disease modelling, outbreak analytics, and model fitting

Resource Provider / format Level Main topics Notes
Infectious Disease Modelling Specialization Imperial College London / Coursera Beginner to intermediate SIR models, R implementation, interventions, calibration, stochastic and deterministic models Core. Good bridge from regression/statistics to transmission models.
Introduction to Infectious Disease Modelling and its Applications LSHTM / short course Beginner to intermediate Infectious disease modelling theory, simple dynamic models, public-health applications Recommended. Professional-training style introduction.
Modern Techniques in Infectious Disease Modelling LSHTM / short course Intermediate R, ODEs, deSolve, stochastic models, metapopulation models, network Reed–Frost models, sensitivity analysis Core. Practical course for implementing deterministic and stochastic models.
Model Fitting and Inference for Infectious Disease Dynamics LSHTM / short course Advanced MCMC, particle filters, ABC, observation models, model checking, stochastic dynamic models Core. Directly relevant to fitting stochastic transmission models.
Outbreak Analytics and Applied Modelling in R LSHTM / short course Intermediate Linelist processing, Rt estimation, severity estimation, forecasting, scenario modelling, outbreak analytics R packages Recommended. Good for public-health outbreak analytics workflows.
Epiverse-TRACE learning materials Epiverse-TRACE / online tutorials Beginner to intermediate Outbreak data cleaning, real-time analysis, forecasting, scenario modelling, R workflows Reference. Useful open material for applied outbreak analytics.
Modeling of Infectious Diseases FUN-MOOC / online course Beginner SIR models, \(R_0\), effective reproduction number, interventions, ODE modelling Recommended. Accessible mathematical modelling introduction.
Pasteur Course: Modeling of Infectious Diseases Institut Pasteur / short course Beginner to intermediate Mathematical modelling of infectious diseases, public-health applications Recommended / recurring. Track for future editions.
Infectious Disease Modeling in Practice Johns Hopkins / Coursera Beginner Model use cases, assumptions, interpretation, public-health decisions Reference. Good for non-specialists and collaborators.
Infectious Disease Transmission Models for Decision-Makers Johns Hopkins / Coursera Beginner Model types, assumptions, limitations, policy interpretation Reference. Best for decision-makers or non-modellers.

Mathematical epidemiology and stochastic epidemic models

Resource Provider / format Level Main topics Notes
ESPIDAM: European Summer Program in Infectious Disease Analysis and Modelling Stockholm University / summer programme Intermediate to advanced Stochastic epidemic models, networks, data analysis, forecasting, AI/control, phylodynamics Core / recurring. One of the strongest European options for infectious disease modelling training.
Stochastic epidemic models with inference ESPIDAM / course module Advanced Basic stochastic epidemic models, SEIR extensions, multitype models, household models, network epidemics, inference Core. Directly relevant to stochastic epidemic theory.
Networks and contact patterns in infectious disease models ESPIDAM / course module Intermediate to advanced Contact patterns, mobility networks, sexual networks, dynamic networks, metapopulation models Core for network/contact modelling. Highly relevant to contact matrices, STI, mpox, and mobility.
Infectious disease data analysis ESPIDAM / course module Intermediate to advanced Bayesian inference, transmission model calibration, serological data, reconstruction of pathogen circulation Recommended. Strong model-data integration component.
Network Modeling for Epidemics SISMID / EpiModel course material Intermediate to advanced ERGM, TERGM, dynamic networks, stochastic network simulation, EpiModel Specialized. Useful for network-based epidemic simulation.
SISMID Emory University / modular summer institute Intermediate to advanced Statistics and modelling in infectious diseases, network modelling, transmission dynamics, inference Specialized / recurring. Check eligibility and location restrictions.

Probability and stochastic processes foundations

Resource Provider / format Level Main topics Notes
Introduction to Stochastic Processes MIT OpenCourseWare Advanced undergraduate / graduate Markov chains, random walks, martingales, Galton–Watson trees Core reference. Useful for branching-process approximations and extinction probabilities.
Discrete Stochastic Processes MIT OpenCourseWare Advanced undergraduate / graduate Discrete stochastic processes, renewal processes, Markov chains, queueing Reference. More engineering/applied-probability oriented.
Probability – The Science of Uncertainty and Data MITx / edX Beginner to intermediate Probability, uncertainty, inference, Markov chains Recommended. Good prerequisite if probability theory needs strengthening.
Discrete-Time Markov Chains and Monte Carlo Methods Coursera Beginner to intermediate Transition matrices, absorbing states, limiting distributions, Monte Carlo methods Reference. Useful entry point for Markov-chain intuition.

Networks and Complex Systems Barcelona School of Economics / summer school Intermediate Random graphs, percolation, contagion, diffusion, resilience, complex systems Specialized. Economic and social systems orientation.
MethodsNET Summer School with CEU MethodsNET / CEU summer school Beginner to advanced Applied social network analysis, discourse network analysis, inferential network analysis Recommended. Social-science network methods.

Books, papers, and reference materials

Resource Type Level Main topics Notes
Mathematical Tools for Understanding Infectious Disease Dynamics Textbook Intermediate to advanced Deterministic and stochastic infectious disease dynamics, \(R_0\), next-generation matrices, model formulation Core. Main theoretical reference for mathematical epidemiology.
Modeling Infectious Diseases in Humans and Animals Textbook Intermediate Epidemic models, heterogeneity, multi-pathogen and multi-host models, stochastic dynamics, spatial models, control Core reference. Strong applied model catalogue.
A primer on stochastic epidemic models Primer paper Intermediate CTMC, SDE, stochastic SIR, host-vector models, outbreak probability Core reference. Short entry point to stochastic epidemic models.
A primer on the use of probability generating functions in infectious disease modeling Tutorial paper Intermediate Probability generating functions, early outbreak, epidemic probability, final size Specialized. Useful for branching-process and PGF intuition.
Introduction to statistical inference for infectious diseases Tutorial / review Intermediate to advanced Stochastic epidemic inference, \(R_0\), final size, temporal data Reference. Good overview of inference for stochastic epidemic models.
Stochastic epidemics in a homogeneous community Lecture notes Advanced Stochastic compartmental epidemics, early phase, final size, law of large numbers, central limit theorem Specialized. Mathematical treatment of stochastic epidemics.
Epidemic modelling: aspects where stochasticity matters Perspective / short paper Intermediate When stochasticity matters, outbreak probability, early epidemic growth Reference. Useful conceptual note on stochasticity in epidemic models.
